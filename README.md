# Personal Finance \& Expense Analysis

## Project Overview

This project analyzes a three-month fictional personal expense dataset to identify spending patterns across expense categories, months, and payment methods.

The project demonstrates practical data analysis and reporting skills using spreadsheet-based data cleaning, analysis, visualization, and dashboard design.

## Business Questions

The analysis aims to answer:

1. How much was spent during the analysis period?
2. Which expense category had the highest spending?
3. How did expenses change from January to March?
4. Which payment method accounted for the largest share of spending?
5. What patterns could be useful for financial planning?

## Dataset

- **Period:** January–March 2026
- **Transactions:** 19
- **Total expenditure:** ₹10,626
- **Dataset type:** Fictional / portfolio dataset

The dataset contains:

- Transaction ID
- Date
- Description
- Category
- Payment Method
- Amount (INR)

## Data Cleaning

The dataset was reviewed and cleaned before analysis.

Cleaning steps included:

- Identifying and removing a duplicate transaction
- Filling a missing expense category
- Standardizing payment-method values
- Checking date and amount fields
- Verifying transaction counts and totals

## Analysis Performed

The project includes:

- Total expense calculation
- Transaction count
- Average transaction value
- Category-wise expense analysis
- Monthly expense analysis
- Payment-method analysis
- Data visualization
- KPI dashboard

## Key Findings

### 1. Total Spending

Total expenditure was **₹10,626 across 19 transactions**.

### 2. Highest Spending Category

Food was the largest expense category at **₹4,460**, representing approximately **42% of total expenditure**.

### 3. Monthly Spending

Monthly expenditure increased during the three-month period:

| Month | Expense |
| --- | ---: |
| January | ₹3,349 |
| February | ₹3,599 |
| March | ₹2,428 |

March recorded the highest monthly expenditure.

### 4. Payment Method

UPI accounted for approximately **93.4%** of total expenditure, while cash accounted for approximately **6.6%**.

### 5. Main Observation

Food represented the largest spending category in the dataset. Regular category-level tracking could help identify recurring spending patterns.

## Recommendations

Based on the sample data:

- Monitor food-related expenditure regularly.
- Continue tracking monthly spending to identify longer-term trends.
- Maintain consistent expense categories for easier comparison.
- Review spending patterns periodically rather than relying only on total expenditure.

## Limitations

This project uses a small fictional dataset created for portfolio and learning purposes.

The dataset covers only three months and does not contain income, savings, debt, household, or other financial information. Therefore, the findings should not be interpreted as conclusions about long-term financial behaviour.
